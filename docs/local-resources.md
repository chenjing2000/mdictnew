# 独立 CSS 与同目录资源读取

日期：2026-10-12。

韦氏高阶英汉双解词典的 apple 正文引用 `mwalecd.css`，该文件在 MDX 旁边独立存放，配套 MDD 内没有对应键。原 DictionaryService 仅调用 Core 的 MDD 读取接口，造成正文可查、CSS 不可用。真实浏览器显示 CSS 成功数为 0，词头背景透明。只在诊断浏览器内存中应用原 CSS 后排版恢复，确认是资源来源缺失，而不是 CSS 内容损坏。

修复位于 `Mdict.Application/DictionaryService.cs`：先调用原 MDD 读取；未命中时按请求路径读取当前 MDX 同目录或子目录文件。MDD 仍优先，异常和歧义不被吞掉。保持服务锁、资源字节、浏览器校验、查词及历史行为；不修改词典原文件。局部 helper 拒绝目录穿越、Windows 尾随点/空格及无效文件名，并拒绝资源文件和中间子目录重解析点。

验证：

- 新增独立 CSS 用例在旧代码上失败；修复后独立资源 7 项通过，涵盖无 MDD、独立 CSS、多词典隔离、子目录资源、MDD 优先、非法路径、缺失文件及关闭行为。
- 实际韦氏浏览器无样式注入时，`mwalecd.css` 返回 HTTP 200，读取到 829 条 CSS 规则，词头背景为 `rgb(231, 245, 245)`，截图已检查。
- 完整 Oxford/WPF 集成 116 项通过，包含一个新独立 CSS 与另一词典 MDD 隔离检查。
- Core 28 项、EntryBridge 12 项、LayoutBridge 9 项通过，加上上述检查共 172 项。
- 主解决方案及测试项目 Release 构建零警告、零错误。

当时的词典诊断日志、截图和 WPF 日志已在统一清理时删除，以上验证结果记录保留。

原 CSS 引用 PrivateA 字体，但原目录与 MDD 均未找到；本次不虚构或替换字体。浏览器自动请求 favicon 返回 404 仍会计入首次页面资源失败，不影响 CSS。实际音频试听及全部第三方词典兼容性不在本次验收范围。
