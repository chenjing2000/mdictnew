# 模块职责与数据流

## 结论

现有 `WPF -> Application -> Core` 单向依赖符合这个小型桌面程序的规模。模块职责基本集中，没有必要新增接口层、依赖注入容器、通用插件框架或基础窗口类。整理只处理实际缺陷、未使用成员和难读代码，保留实际调用接口、文件格式与交互规则。

## 职责与所有权

| 模块 / 文件 | 职责 | 不负责的内容 |
| --- | --- | --- |
| `Mdict.Core` | MDX/MDD 头部、Key / Record 索引、解压、校验和、资源读取 | WPF、WebView2、设置与历史 |
| `OxfordDictionary` | 一个 MDX 及其匹配 MDD 分卷；按需加载和查词 | 多词典编排与线程调度 |
| `Mdict.Application/DictionaryService` | 对读者的简单封装；统一同步锁、打开、查询、关闭；MDD 未命中时读取当前词典目录中的资源 | UI、浏览器导航和历史 |
| `MainWindow` | 输入、候选防抖、全部词典查询、统一历史、配置切换和滚动 | 二进制解析、HTTP 资源生成 |
| `DictionaryResultView` | 单个结果区的标题、服务、浏览器、控制器及释放 | 全局历史和词典列表持久化 |
| `DictionarySettings` | 路径规范化、校验及 JSON 读写 | 设置控件和词典内容 |
| `SettingsWindow` | 最多 8 行路径编辑、图标、保存或取消 | 主窗口查词与历史 |
| `WindowSizeLimits` | 两个窗口的最大尺寸、当前显示器工作区、DPI 换算与原始最小尺寸恢复 | 查词、配置和图标 |
| `WebViewController` | 每个浏览器的导航、脚本注入、消息、高度和关闭 | MDX 二进制与全局历史 |
| `WebResourceHandler` | 当前词典页面与资源响应、MIME、音频范围请求和统计 | 设置和跨词典查询 |
| 三个 JS Bridge | 分别处理音频、内部词条、布局 / 锚点 / 缩放 | MDX 文件与设置 |

`MdictReaderTest` 提供 CLI 和小型合成文件自测；`dev-tests/Mdict.Wpf.Tests` 使用真实 WPF/WebView2 与词典进行集成检查。测试中的反射与合成 fixture 不属于程序运行时架构。

## 一次查词的数据流

1. 回车、候选或内部词条链接进入主窗口同一个查询入口，先隐藏全部旧结果；空输入回车也清空显示。
2. 主窗口在后台逐一调用各结果区的 `DictionaryService.Lookup`，收集 HTML 或该词典的错误。
3. 服务锁保护 Core 的延迟索引和缓存；每个结果区有自己的服务，不共享读者状态。
4. 主窗口回到 UI 线程，只显示非空白 HTML 的结果区，首次命中时初始化浏览器。页面加载期间隐藏旧浏览器画面，加载成功后展开显示；错误汇总到底部。资源请求只调用该区服务，词典 CSS、图片与音频不会串用。
5. 至少一个词典成功显示时，更新统一历史；全部未命中时结果区留空，不新增历史。
6. 后退 / 前进重新查询全部词典，不另增历史项。配置切换重建结果区并重置历史。

服务的同步锁不仅保护查词，也保护候选和资源读取。Core 本身不承诺线程安全；CLI 单线程调用可直接使用，UI 并发路径通过服务访问。

独立资源由 Application 层读取，不改变 Core 的 MDD 接口：先保留现有 MDD 精确及唯一文件名匹配，返回未命中后才读取 MDX 同目录或子目录。路径拒绝空段、尾随点/空格和无效文件名字符；资源文件及中间子目录的重解析点不被跟随。浏览器原有来源、请求方法、MIME 和 URL 校验继续生效。

## 状态与关闭

- MDX 只有在 Header、Key、Record 三者全部读取成功后才发布索引；失败保留未加载状态，后续可重试。
- 候选通过防抖、版本检查和取消状态避免旧查询回写；UI 控件只在 UI 线程更新。
- 每个结果区负责自己的浏览器生命周期。控制器和资源处理器解除回调并处理关闭期间的请求，不让释放后的结果区继续更新。
- 保存设置发生在验证后；取消不修改当前配置。命令行路径优先于保存配置，只影响本次启动。
- 启动没有默认搜索文字，不显示词典名称和容器，也不初始化浏览器或导航到示例词/旧查询。首次有结果时初始化该词典的浏览器；折叠仅隐藏浏览器，不释放它。配置切换仍重新查询已显示词。
- 窗口尺寸限制响应位置、DPI 与工作区 / 显示器变更。原生消息 hook 随窗口关闭或 HwndSource 释放，不使用全局事件订阅。
- 未配置可用词典时，浏览器自测初始化失败会释放并移除临时结果区；环境恢复后可重新自测，不保留未初始化对象。

## 保留的必要复杂度

异步、事件回调、锁和请求版本号是为响应性、线程安全与取消顺序服务的，不是多余抽象。三字段命名元组只用于局部查询结果，避免新增仅使用一次的结果类；普通 LINQ 保留在清楚的集合操作中，复杂查询分支已改为显式循环。

MainWindow 的输入、历史和结果发布有共同状态，继续放在一个窗口编排中比拆成相互回调的多个管理器更直接。部分短小路径处理与启动脚本有重复，但合并成通用框架会增加依赖和理解成本，本次保留。

Core 的格式数据对象、校验与 RIPEMD-128 实现服务于当前读取需求，不为了减少文件数而混入窗口。未采用全局重命名、统一代码风格改写或无依据的性能优化。

## 已知范围

现有读者针对已验证的 MDict 2 格式，支持当前实现的未压缩 / zlib 数据、UTF-8 MDX 和 UTF-16LE MDD，以及 Key Info 加密。不支持 LZO 等未实现变体。精确与前缀查询仍使用现有线性扫描；资源索引按需加载，后续优化应以实际测量为依据。
