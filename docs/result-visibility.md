# 查询刷新、隐藏容器与折叠

日期：2026-10-12。按用户确认的交互修改，不改 MDX/MDD 文件及设置格式。

- 标题继续使用 MDX 文件名（不带扩展名），不读取词典元数据标题。
- 标题左侧增加按钮：向下箭头收起正文，向右箭头展开正文。折叠时保留标题并移除正文的布局空间，词典和浏览器仍保持打开。
- 启动打开词典服务，但隐藏全部结果区，不创建词条索引；浏览器首次命中后初始化。
- 每次查询立即隐藏旧结果，空输入回车也清空。仅非空白 HTML 的词典结果按配置顺序显示，新结果默认展开；未命中、空白结果、打开或显示失败的容器不出现，错误写入底部状态栏。
- 全部未命中时结果区留空，不新增历史。正常候选、内部链接和前进/后退共用上述结果更新逻辑。
- 页面导航期间浏览器处于 Hidden，参与首次初始化的布局但不暴露旧页面。完成后才显示新正文。F9 诊断失败时也隐藏其空容器。
- 词条页面允许无文字但包含图片等内容；诊断页仍要求有文字。HTML 是否有内容按非空白判断，不基于纯文本判断。
