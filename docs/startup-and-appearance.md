# 启动与窗口外观调整

当前主窗口不再设置 MaxWidth/MaxHeight，也不随工作区变化重设上限；最小尺寸为 450×450，最大化由 Windows 正常管理。设置窗口继续保留 500×500 与当前工作区取较小值的限制。词典名称与三角形填充、描边统一为 `#ecebc2`，三角形按钮背景透明，标题行背景仍为 `#007175`。

主窗口标题仅显示 `MdictViewer`；输入框最小宽度 100、高度 30、字号 15、内边距 10,3，实际宽度仍随窗口伸缩。右侧三个按钮为 30×30，后退/前进箭头和设置图标同步缩小。尺寸使用 WPF 逻辑像素；两个窗口外轮廓继续采用系统边框，没有添加自定义圆角。

候选框在输入框失去键盘焦点、主窗口开始移动或缩放、查询或按 Esc 时关闭。关闭复用原函数，同时取消定时器、待处理请求并使后台旧结果失效。窗口移动使用 WM_ENTERSIZEMOVE，因此即使输入框仍保留焦点也能关闭候选框。鼠标候选在按下时提交查询，失焦处理延迟至候选点击处理后；仅重新聚焦不自动弹出。

## 变更

- 删除搜索框默认的 `apple`，取消浏览器初始化时的提示页导航。启动只打开配置的词典，输入框、词条页和统一查询历史为空，词条索引仍未加载。不会恢复上次查询词。
- 空输入按回车不查询、不写历史；用户查词后修改配置，仍重新查询当前已显示词。
- 设置页标题、路径输入、提示、保存及取消按钮统一继承字号 15。系统标题栏与系统文件选择对话框仍由 Windows 决定字体。
- 主窗口最大尺寸直接等于当前显示器工作区，不再设 `1600 × 1000` 固定上限，可最大化占满可用工作区而不遮挡任务栏。设置窗口仍最大 `1000 × 700`，取该上限与工作区的较小值。尺寸单位为逻辑像素。
- 保留主窗口 `620 × 450`、设置窗口 `520 × 320` 的原始最小尺寸。工作区比最小尺寸还小时临时缩小，返回较大工作区后恢复原值。
- 在窗口移动、DPI 变化、工作区或显示器变更时重新计算限制；使用 Win32 工作区和 WPF 变换换算物理 / 逻辑像素。原生消息 hook 随窗口生命周期释放。

没有修改 Core、Application、词典设置格式或历史持久化方式；查询历史仍只有当前窗口的内存状态。个人词典配置未改写。

## Logo

`Mdict.Wpf/Assets/Logo.xaml` 是绘制源：`#ddc5b8` 圆形底色，`#106898` 曲线路径 M，透明外围。字母带变化的笔画宽度和弧形衬线，不依赖任何字体字符。

按后续确认，圆形半径从 120 增至 126（256 像素画布），减少外围留白；M 以画布中心放大 15%，没有裁切。Windows 标题栏和任务栏的图标容器尺寸不变。

`Assets/App.ico` 包含 16、24、32、48、64、128 和 256 像素帧，使用超采样和平滑缩放生成。两种窗口引用同一图标，项目 `ApplicationIcon` 将它嵌入 EXE。常规构建直接使用仓库里的 ICO，不需要重新生成。

修改绘制源后，可在项目根目录重新生成：

```powershell
& "$env:WINDIR\System32\WindowsPowerShell\v1.0\powershell.exe" -NoProfile -STA -ExecutionPolicy Bypass -File .\tools\Generate-AppIcon.ps1
```

该命令只在这个进程中允许运行仓库自己的生成脚本，不修改系统执行策略；脚本仅生成 `Mdict.Wpf/Assets/App.ico`。应用编译与运行仍使用 .NET 10。
